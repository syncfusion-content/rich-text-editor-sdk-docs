# Syncfusion<sup style="font-size:70%">&reg;</sup> React MCP Server

The Syncfusion<sup style="font-size:70%">&reg;</sup> MCP Server accelerates React application development by providing deep component knowledge directly in your AI-powered IDE. [Model Context Protocol](https://modelcontextprotocol.io/docs/getting-started/intro) (MCP) integration enables quick access to documentation, API references, and code-generation features for the Rich Text Editor SDK from within the development environment.

## Key benefits

- **Expert component knowledge** — deep understanding of the React Rich Text Editor, Block Editor, and Markdown Editor implementation patterns.
- **Unlimited usage** — no request limits, time restrictions, or query caps.
- **Privacy-focused** — the tools operate based on the user's query and do not store any content, data, or prompts.

## Installation

### Prerequisites

- **Node.js** version 18 or higher.
- A **compatible MCP client** (VS Code, Syncfusion<sup style="font-size:70%">&reg;</sup> Code Studio, Cursor, JetBrains, etc.).
- An active [Syncfusion<sup style="font-size:70%">&reg;</sup> API key](https://syncfusion.com/account/api-key).
- A **React application** (existing or new); see the [Quick Start](../rich-text-editor/quick-start).
- An active Syncfusion<sup style="font-size:70%">&reg;</sup> license (Commercial, Free Community, or Free Trial).

### Using the MCP Server

Once configured in your MCP client, prompt the assistant to build or configure the Rich Text Editor. Use the `search_docs` tool to fetch accurate documentation and API references while generating code.
