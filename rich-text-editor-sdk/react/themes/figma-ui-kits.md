# Figma UI Kits

The [Syncfusion<sup style="font-size:70%">&reg;</sup> Web UI Kit](https://www.syncfusion.com/downloads/ui-kit) provides Figma design assets that mirror the built-in themes of the Rich Text Editor SDK components. Designers can build mockups and prototypes that map one-to-one to the rendered React components, ensuring design and implementation stay in sync.

## What's included

- Component designs aligned with themes such as Material 3, Fluent 2, Bootstrap 5.3, and Tailwind 3.4.
- Light and dark variants.
- Reusable variants for interactive states (default, hover, active, disabled).

## Using the UI Kit

1. Download the UI Kit for your preferred theme from the [UI Kit page](https://www.syncfusion.com/downloads/ui-kit).
2. Import the file into Figma.
3. Use the pre-built component variants to design your editor screens.
4. Implement the design using the matching Syncfusion<sup style="font-size:70%">&reg;</sup> React theme so the result matches the mockup.
