# React Rich Text Editor SDK version compatibility

## React version compatibility

The following table lists the supported React versions and the minimum Syncfusion<sup style="font-size:70%">&reg;</sup> React Rich Text Editor package version (`@syncfusion/ej2-react-richtexteditor`) that is compatible with each. The same version floor applies to the Block Editor (`@syncfusion/ej2-react-blockeditor`) and Markdown Editor (`@syncfusion/ej2-react-richtexteditor` markdown mode).

| React version | Minimum supported Syncfusion React Rich Text Editor package version |
| ------------- | ----------------------------------------------------------------- |
| [React v19](https://react.dev/) | 29.1.33 and above |
| [React v18](https://reactjs.org/blog/2022/03/29/react-v18.html) | 20.2.36 and above |
| [React v17](https://reactjs.org/blog/2020/10/20/react-v17.html) | 18.3.50 and above |
| [React v16](https://reactjs.org/blog/2017/09/26/react-v16.0.html) | 16.2.45 and above |

> The Rich Text Editor package name has remained `@syncfusion/ej2-react-richtexteditor` across these versions; only the version number changes.

## Syncfusion<sup style="font-size:70%">&reg;</sup> version information

Syncfusion<sup style="font-size:70%">&reg;</sup> follows a quarterly release schedule, publishing a major volume every three months. Releases use a **Major.Minor.Revision** versioning scheme to make change tracking predictable.

For example, version `22.1.34` is interpreted as:

* **22** — major volume (quarterly release). Major volumes may include significant updates and possible breaking changes.
* **1** — minor release within the major volume (feature additions and bug fixes that are generally non-breaking).
* **34** — revision or patch number (bug fixes and small updates).

Refer to the [Release Notes](./release-notes-index) and the [Upgrade guide](../installation/upgrade) to verify compatibility and identify any breaking changes before updating packages.
