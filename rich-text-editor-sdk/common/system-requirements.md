# System Requirements

This guide outlines the system requirements to use the Syncfusion<sup style="font-size:70%">&reg;</sup> Rich Text Editor SDK effectively. The requirements are common across all supported frameworks, with framework-specific versions noted where applicable.

## Development environment

- **Node.js:** Use Node.js version 18.0.0 or above. The compatible npm version is installed along with Node.js. To verify the Node.js installation, run:

  ```bash
  node --version
  ```

- **Package manager:** npm (bundled with Node.js), Yarn (>= 1.x), or pnpm.

## Framework support

The Rich Text Editor SDK ships tailored packages for each supported framework. The minimum framework versions are listed below.

| Framework | Minimum supported version |
|-----------|---------------------------|
| React | 15.5.4 or higher (React 16/17/18/19 supported) |
| Angular | Angular 4 or higher |
| Vue | Vue 2 and Vue 3 |
| JavaScript / TypeScript | ES5+ (TypeScript 3.0 or higher recommended) |
| Blazor | .NET 6.0 or higher |
| ASP.NET Core | .NET 6.0 or higher |
| ASP.NET MVC | .NET Framework 4.5 or higher |
| .NET MAUI | .NET 7.0 or higher |

> For detailed, version-by-version compatibility between a framework and the Syncfusion<sup style="font-size:70%">&reg;</sup> package versions, refer to the [Upgrade](../installation/upgrade) documentation.

## Browser support

The Syncfusion<sup style="font-size:70%">&reg;</sup> Rich Text Editor SDK components are supported in all modern browsers, including the latest versions of:

- Google Chrome
- Mozilla Firefox
- Microsoft Edge (Chromium)
- Apple Safari
