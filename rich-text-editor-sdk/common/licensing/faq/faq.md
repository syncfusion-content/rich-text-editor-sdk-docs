# Licensing FAQ

## Is an internet connection required for license validation?

No. Syncfusion<sup style="font-size:70%">&reg;</sup> Essential Studio<sup style="font-size:70%">&reg;</sup> license validation is performed offline during application execution. Apps registered with a Syncfusion<sup style="font-size:70%">&reg;</sup> license key can be deployed on any system without an internet connection.

## How do I upgrade from the trial version after purchasing a license?

There are two possible solutions:

* Uninstall the trial version and install the fully licensed build from the [License & Downloads](https://www.syncfusion.com/account/downloads) section of the Syncfusion<sup style="font-size:70%">&reg;</sup> website.
* If you are using Syncfusion<sup style="font-size:70%">&reg;</sup> controls from [npm](https://www.npmjs.com/search?q=scope:syncfusion) or NuGet, replace the trial license key with a paid license key generated from the [License & Downloads](https://www.syncfusion.com/account/downloads) section.

## Where can I get a license key?

License keys can be generated from the [License & Downloads](https://syncfusion.com/account/downloads) or [Trial & Downloads](https://www.syncfusion.com/account/manage-trials/downloads) section of the Syncfusion<sup style="font-size:70%">&reg;</sup> website. Keys are **version and platform-specific**.

## Will the registered license key expire?

No, Syncfusion<sup style="font-size:70%">&reg;</sup> license keys do not expire for a particular version, and you can continue to use them. If you have used a trial key, it will expire in 30 days, and using it in production is not recommended.
