# Release Notes

The Syncfusion<sup style="font-size:70%">&reg;</sup> Rich Text Editor SDK follows a quarterly volume release cadence, with Service Pack releases in between to deliver bug fixes. Release notes document the new features, enhancements, and bug fixes for the Rich Text Editor, Block Editor, and Markdown Editor components.

## Latest release notes

Detailed, version-by-version release notes are maintained in the [Release Notes](../Release-Notes/) section.

## What each release note covers

- **New features** — capabilities added to the components.
- **Enhancements** — improvements to existing behavior and APIs.
- **Bug fixes** — resolved issues, grouped by component.
- **Breaking changes** — any API or behavioral changes that may require updates in your application.
