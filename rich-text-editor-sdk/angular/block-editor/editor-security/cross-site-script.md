# XSS Prevention in Angular Block Editor

The Block Editor is hardened against cross-site scripting (XSS). It ships with the HTML sanitizer enabled by default, which strips dangerous tags (such as `<script>`) and event handler attributes (such as `onmouseover`) from any content rendered in the editor.

## Enabling XSS prevention

XSS prevention is controlled by the [enableHtmlSanitizer](https://ej2.syncfusion.com/angular/documentation/api/blockeditor/index-default#enablehtmlsanitizer) property on the editor, which defaults to `true`. When the sanitizer is on, the editor removes any element or attribute that could execute a script. > **Warning:** Disabling `enableHtmlSanitizer` (by setting it to `false`) re-enables the execution of any script tags and event handlers in the editor content. Only do this if your content is fully trusted (for example, generated by your own server), and never with user-supplied property. For finer-grained control over what is allowed during paste, see [pasteCleanupSettings](https://ej2.syncfusion.com/angular/documentation/api/blockeditor/index-default#pastecleanupsettings).
